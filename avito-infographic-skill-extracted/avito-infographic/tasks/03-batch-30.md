# Задание 03 — пакетная генерация по 30 объявлениям

Готовый промпт для Claude Code. Связка скила avito-infographic с папкой текстов
объявлений (из ai-agenty-avito-zadanie.md, ПРОМПТ A).

```
Прогони скил avito-infographic по всем текстам объявлений в
prompts/listings/ai-agents/.

Для каждого файла-объявления:
1. По заданию tasks/01-extract.md собери listing.json → сохрани в data/.
2. По заданию tasks/02-render.md отрендерь комплект в out/<номер>-<ключ>/.

Уникализация комплектов (анти-дубль Авито):
- Меняй tagline, подсвеченный key и набор/порядок результатов между объявлениями.
- Не допускай одинаковых цифр и заголовков на разных комплектах.
- Шаблон один — это нормально; контент и кейсы должны отличаться.

На выходе:
- data/ — 30 listing.json
- out/ — 30 папок с PNG
- сводка: таблица «№ | объявление | число слайдов | статус рендера».
Соблюдай правила «по-белому» из SKILL.md по каждому комплекту.
```
