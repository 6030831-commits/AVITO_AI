# Задание 01 — текст объявления → listing.json

Готовый промпт для агента. Скармливать вместе с текстом одного объявления.

```
Ты — генератор данных для инфографики Авито. Прочитай текст объявления ниже и собери
listing.json СТРОГО по схеме скила avito-infographic (см. examples/sample-slides.json).

Жёсткие правила:
- Все числа (отзывы, %, сроки, средний чек, кол-во кейсов) бери ТОЛЬКО из текста.
  Если числа в тексте нет — соответствующий результат/бейдж НЕ включай. Не выдумывай.
- В headline.key вынеси одно ключевое слово заголовка (его подсветим).
- tagline — 3 коротких слова-обещания (из тона объявления).
- cases[]: на каждый реальный кейс из текста — объект с niche, body (1–2 предложения),
  results[] (только реально названные цифры), days (если указан срок), коротким
  диалогом chat[] (придумай правдоподобный сценарий ПОД НИШУ, без обещаний-цифр),
  options[] (2 кнопки выбора).
- includes[]: 4–6 этапов работ, если они есть/подразумеваются в тексте.
- stack[]: упомянутые каналы/интеграции (текстом, без логотипов).
- cta: призыв + бесплатная консультация; promo — только если промокод есть в тексте.
- НИКАКИХ контактов (телефон/Telegram/сайт/email) ни в одном поле.

Верни ТОЛЬКО валидный JSON, без markdown-обёртки и комментариев.

ТЕКСТ ОБЪЯВЛЕНИЯ:
<<< сюда вставить текст одного объявления >>>
```

После получения JSON — сохранить как `data/<номер>-<ключ>.json`.
