# Avito Infographic Skill

Превращает **текст объявления** в **комплект инфографик** в стиле конкурента-
референса. Стиль зашит в шаблон, агент подставляет только контент и **реальные
цифры из текста**. Один JSON → весь комплект.

Пайплайн: `текст объявления` → (агент) `listing.json` → (рендер) `PNG ×N`.

---

## Что производит скил

Из одного `listing.json` шаблон собирает комплект слайдов 1280×960 (4:3, формат Авито):

1. **offer** — оффер-баннер: 3 пилла-обещания + крупный заголовок с подсвеченным
   ключевым словом (градиент + glow + пунктирная рамка-«выделение») + маленький
   маскот у ключа + **крупное фото владельца справа** + глянцевые карточки доверия.
2. **case** — кейс: мокап телефона с диалогом бота + ниша + что внедрили +
   результат в цифрах + колаут «Разработано за N дней».
3. **includes** — «Всё под ключ»: пронумерованные этапы.
4. **stack** — «Подключаем куда угодно»: чипы интеграций (без брендовых логотипов).
5. **cta** — призыв + бесплатная консультация + промокод.

Слайды 2–5 в правом верхнем углу несут **кружок-аватар с лицом владельца** — фото
присутствует во всём комплекте, не перегружая контент.

---

## Ваше фото (`assets/face.png`)

Лицо вставляется автоматически на все слайды, если положить файл и указать его в JSON:

1. Подготовь **фото-вырезку без фона** (PNG с прозрачностью), по плечи, лицо смотрит
   влево/в кадр. Удобно: remove.bg, Nano Banana, Photoshop. Желательно вертикальный
   кадр и резкое лицо (на оффере оно крупное).
2. Положи в `assets/face.png`.
3. В `listing.json` укажи `"photo": "face.png"`. Путь — относительно `template.html`
   (оба в `assets/`). Хочешь без фото — поставь `null`, покажется рамка-плейсхолдер.

Фото — общий брендовый элемент: один и тот же `face.png` идёт во все 30 комплектов,
менять его в каждом объявлении не нужно.

## Файлы скила

```
avito-infographic/
  SKILL.md              ← этот файл
  assets/
    template.html       ← движок: читает window.LISTING, строит все слайды
    tokens.css          ← палитра/шрифты (справочно; в template.html всё инлайн)
  scripts/
    render.mjs          ← Node + Playwright: listing.json → PNG по слайдам
    package.json
  tasks/
    01-extract.md       ← задание: текст объявления → listing.json
    02-render.md         ← задание: рендер комплекта

  examples/
    sample-listing.md   ← пример входного текста
    sample-slides.json  ← пример заполненного JSON (= схема)
```

## Модель данных (`listing.json`)

Агент заполняет ТОЛЬКО из текста объявления. Чего нет в тексте — не выдумывать
(пропустить поле/чип, а не сочинять).

```jsonc
{
  "photo": "face.png",                                 // ваше фото-вырезка (PNG без фона) в assets/; null → плейсхолдер
  "tagline": ["Быстро","Качественно","Красиво"],     // 3 коротких слова в пиллы
  "headline": {"pre":"Разработка и внедрение","key":"ИИ-агентов","post":""}, // key = подсветить
  "subline": ["Индивидуально под","ваш бизнес"],       // последняя строка → акцент
  "badges": [                                          // карточки доверия (real!)
    {"type":"shield","text":"Вся работа под ключ"},
    {"type":"stars","text":"200+ отзывов"}             // число — ТОЛЬКО реальное
  ],
  "cases": [{                                          // ≥1 кейс из текста
    "niche":"для химчистки",
    "body":"Что внедрили — 1–2 предложения из текста.",
    "results":[{"v":"70%","l":"заказов онлайн"},       // цифры из текста; нет — убрать чип
              {"v":"+18%","l":"средний чек"}],
    "days":7,
    "chat":[{"side":"in","text":"..."},{"side":"out","text":"..."}], // короткий диалог
    "options":["Вариант А","Вариант Б"]
  }],
  "includes":[{"t":"Аудит","d":"короткое пояснение"}, ...],  // 4–6 этапов
  "stack":["Telegram","WhatsApp","Сайт","amoCRM","Авито"],   // текст, без логотипов
  "cta":{"headline":["Напишите","прямо сейчас"],
         "sub":"Бесплатная консультация и расчёт под нишу",
         "promo":{"code":"АВИТО","value":"15"}}            // promo опционально
}
```

Полный валидный пример — `examples/sample-slides.json`.

## Правила «по-белому» (зашить в агента, не нарушать)

1. **Цифры только реальные.** Все числа (отзывы, %, дни, чек) агент берёт ИЗ ТЕКСТА
   объявления. Нет числа в тексте — поле/чип убрать, не сочинять. Это та же логика,
   что запрет фейковых артикулов/ГОСТ в copywriter.
2. **Никаких контактов на картинках.** Телефон, Telegram, сайт, email — НЕ в слайдах.
   Водяной знак с контактом = нарушение правил Авито. CTA уводит только в чат Авито.
3. **Маскот — generic.** Робот в шаблоне геометрический и нейтральный. Не выдавать его
   за Claude/Anthropic и не подставлять чужих персонажей (IP).
4. **Лицо — только своё** или честно лицензированное фото. Чужое из референса нельзя.
5. **Один подсвеченный ключ на слайд** (поле `key`) — не перегружать.
6. **Шрифт Montserrat (OFL, свободная лицензия).** Для офлайн-рендера — самохостинг
   (см. render.mjs).

## Как работает агент (порядок)

1. Прочитать текст объявления (из `prompts/listings/.../*.md` или вставленный).
2. По заданию `tasks/01-extract.md` собрать `listing.json` строго по схеме выше.
   Заголовок ≤ длины строки баннера; `body` кейса — 1–2 предложения; в `results`
   только реально упомянутые числа.
3. По заданию `tasks/02-render.md` отрендерить PNG.
4. Для всех 30 — `tasks/03-batch-30.md`.

## Рендер (в окружении владельца)

```bash
cd avito-infographic/scripts
npm install              # playwright
npx playwright install chromium
node render.mjs ../examples/sample-slides.json ../out   # → out/offer.png, out/case_1.png, ...
```

`render.mjs`: ставит viewport 1280×960, инжектит `window.LISTING`, грузит
`assets/template.html`, скриншотит каждый элемент `.slide` отдельным PNG.

> Если рендер недоступен локально — `template.html` можно просто открыть в браузере
> (он покажет слайды) и снять скрин вручную, либо отдать JSON в дизайн-агента.

## Кастомизация

| Запрос | Как адаптировать |
|---|---|
| Другая палитра | Поменять `--bg-*`/`--neon*` в `:root` template.html |
| Больше кейсов | Добавить объекты в `cases[]` → больше case-слайдов |
| Без промокода | Убрать `cta.promo` |
| Другой формат | Поменять `width/height` в `.slide` (квадрат 1080×1080 и т.п.) |
| Своё фото вместо маскота | Заменить блок `.mascot` на `<img>` |
| Другой стек | Изменить массив `stack[]` |

---

## Памятка по уникализации (анти-дубль Авито)

Для пакета из 30 объявлений визуальная разница достигается данными, не только текстом:
меняй `tagline`, подсвеченный `key`, набор кейсов и порядок результатов. Один и тот же
шаблон — нормально; одинаковые цифры и заголовки на всех — нет.
