# Задание 02 — рендер комплекта PNG

Готовый промпт для Claude Code (выполняется в окружении владельца).

```
Используя скил avito-infographic, отрендерь комплект инфографик из файла
data/<номер>-<ключ>.json.

Шаги:
1. Убедись, что в scripts/ установлен playwright (npm install + npx playwright
   install chromium). Если chromium недоступен в сети — сообщи и оставь JSON готовым
   к ручному рендеру через открытие assets/template.html в браузере.
2. Запусти: node scripts/render.mjs data/<номер>-<ключ>.json out/<номер>-<ключ>/
3. Проверь, что в out/<номер>-<ключ>/ появились PNG 1280×960: offer.png,
   case_1.png (и т.д. по числу кейсов), includes.png, stack.png, cta.png.
4. Проверь визуально по правилам «по-белому» из SKILL.md: нет контактов на картинках,
   нет выдуманных цифр, один подсвеченный ключ на слайд.
5. Выведи список готовых файлов.
```
