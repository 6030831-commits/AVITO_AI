# Шаблон одного объявления (для папки с готовыми листингами)

> Один файл = одно объявление. Имя файла: `NN-направление-ключ.md`
> Заполняется по строке матрицы, с применением чек-листа SEO ([02-seo-checklist.md](02-seo-checklist.md)).

---

```markdown
# [Заголовок ≤ 50–55 символов: Ключевое слово + продукт + применение/аудитория]

**Категория Авито:** [Услуги → раздел → подраздел — точная ветка для вашей тематики]
**Целевой ключ:** [фраза из матрицы — должна быть первой в заголовке]
**Цена / модель:** [конкретное число + единица: «от X ₽/ед.» / «за проект от X ₽» / «расчёт по ТЗ»]
**ФОТО:** [что снять для карточки — 3–5 содержательных пунктов]

---

## ОПИСАНИЕ

[Блок 1 — Бренд/позиционирование: одна строка, суть в 3 словах]

[Блок 2 — Цена крупно, в первом экране: «от X ₽/ед. · минимальный заказ Y ₽»]

---

[Блок 3 — Что входит / для кого: 3–5 пунктов через · или →]

[Блок 4 — Цикл работы через стрелки: «приём заявки → производство → передача»]

[Блок 5 — Технические параметры: конкретные цифры — материалы, размеры, точность, мощности, форматы]

[Доп. условия — варианты материала/исполнения, давальческий материал и т.п., если применимо]

[Блок 6 — Срок: «от N дней/часов»]
[Блок 7 — Бесплатный бонус: «расчёт по чертежу/фото — бесплатно»]

[CTA — конкретное действие + обязательство по времени]

---

## ХАРАКТЕРИСТИКИ (для формы карточки Авито — влияют на ранжирование)

- Вид услуги: [...]
- Материал: [...]
- Параметр 3 (специфичный для ниши — толщина/размер/мощность): [...]
- Формат входных данных (если применимо — файлы, ТЗ, образец): [...]
- Технический параметр (оборудование, точность, объём): [...]
- Срок: [...]
- Минимальный заказ / стартовая цена: [...]
- Доп. условие (давальческий материал / выезд на замер / гарантия): [...]
```

---

## Правила уникализации между файлами

- **5+ структурных вариантов** порядка блоков (не все объявления должны идти Бренд→Цена→Цикл→...;
  чередуйте: Цена→Что делаем→Оборудование→Срок→CTA, Применение→Цикл→Цена→Параметры→Срок и т.д.)
- **5+ вариантов CTA** с разными глаголами и обязательствами по времени
- **Разные первые предложения** — не начинать одинаковыми оборотами
- **Синонимы ключевого действия** — каждое объявление использует свой синоним из списка направления
- Перепроверять скриптом [05-similarity-checker.py](05-similarity-checker.py) — порог 40%

## Жёсткие ограничения (применимы к любой нише)

- Без контактов (телефон/мессенджер/email) в тексте описания
- Без фейковых артикулов, сертификатов, ГОСТ — указывать только то, что реально есть
- Не дописывать характеристики, которых нет в реальности — лучше не указывать поле, чем придумать
- Заголовок — без emoji, без КАПСА, без избыточной пунктуации (Авито может занижать такие в выдаче)
