# Шаблон: план пачечной публикации (без риска склейки в дубли)

> Цель — выложить N готовых объявлений так, чтобы алгоритм Авито не воспринял их как дубли
> и не занизил показы. Работает для любой тематики при N ≥ 15–20.

---

## Принципы

1. **Публиковать пачками с паузой 1–2 дня** между пачками
   — резкий вброс десятков объявлений с одного аккаунта повышает риск ручной/алгоритмической проверки на дубли
2. **Внутри пачки — вперемешку по направлениям**
   — не публиковать подряд 5 объявлений одного направления с похожей структурой текста
3. **Возрастающий размер пачек** (например, 5 → 10 → 15)
   — первая пачка маленькая: если есть проблема с модерацией или текстами, её проще исправить до масштабирования
4. **Фото — сразу или в течение 24 часов**
   — объявления без фото снижаются в выдаче; если фото ещё не готовы, ставить временную заглушку и дозагружать оперативно

## Шаблон распределения (на N объявлений, K направлений)

| Пачка | Размер | Когда | Состав |
|---|---|---|---|
| Пачка 1 | ~15–20% от N | День 1 | По 1 объявлению из каждого направления — «пробный набор» |
| Пачка 2 | ~30–35% от N | День 3–4 (после паузы) | Смешанный состав, разные направления подряд не повторяются |
| Пачка 3 | оставшиеся | День 6–7 | Смешанный состав, оставшиеся объявления |

## Чек-лист на каждую пачку перед публикацией

- [ ] В пачке нет двух объявлений одного направления подряд
- [ ] В каждом объявлении заполнены характеристики карточки (см. [04-listing-template.md](04-listing-template.md))
- [ ] Фото готовы или поставлена явная заглушка с пометкой «дозагрузить»
- [ ] Цена и срок — конкретные числа (не «расчёт» без контекста, если это не свойственно нише)
- [ ] После публикации — занесена ссылка и дата в трекер ([06-tracker-generator.py](06-tracker-generator.py))

## После публикации каждой пачки

1. Обновить статус в трекере: `черновик → на модерации → опубликовано`
2. Через 2–3 дня сверить, что объявления прошли модерацию (не отклонены, не помечены как дубли)
3. Зафиксировать первые просмотры/обращения — это сигнал, нужно ли усиливать конкретные объявления платными инструментами (поднятие, выделение, XL-формат)

## Структура итогового документа для ручной заливки (avito-zalivka.md)

```
# [Тематика] — гайд ручной публикации N объявлений

## Инструкция
   - правило пауз между пачками
   - правило по фото
   - порядок фиксации в трекере

## ПАЧКА 1 — [размер] (день 1)
   ## NN. [Заголовок]
   - Категория Авито: ...
   - Целевой ключ: ...
   - Цена / модель: ...
   - ФОТО: ...
   ОПИСАНИЕ (копировать целиком): [полный текст]
   ХАРАКТЕРИСТИКИ: [список параметров для формы]
   ---
   (повторить для каждого объявления пачки)

## ПАЧКА 2 — [размер] (день N)
   ...

## ПАЧКА 3 — [размер] (день N)
   ...
```
