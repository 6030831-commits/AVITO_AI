# Шаблон: матрица уникальных связок для N объявлений

> Цель — спланировать N объявлений так, чтобы каждое было уникальной комбинацией
> «направление + изделие/применение + материал + ключевой запрос + аудитория + модель цены»,
> а ключевые запросы НЕ повторялись внутри одного направления.

---

## Как использовать

1. Определите 2–4 направления услуг и распределите N объявлений между ними пропорционально
   спросу/маржинальности (например, 15 / 8 / 7 на 30 объявлений)
2. На каждое направление подготовьте список синонимов ключевого действия
   (аналог «раскрой / фрезеровка / резка / распил / изготовление»)
3. Заполните строки матрицы — каждая строка должна отличаться минимум по двум из шести полей
4. Проверьте: внутри направления нет двух одинаковых ключевых запросов

|---|---|---|---|---|---|---|

## Правила уникальности связок

- **Изделие/применение** — конкретный продукт или сценарий использования, не общая категория
  («раскрой деталей корпусной мебели», а не просто «раскрой»)
- **Материал** — указывать с диапазоном толщин/параметров, если это типично для ниши
- **Ключевой запрос** — будущий заголовок: формула `[ключевое слово] + [продукт/материал] + [применение/гео]`,
  не должен пересекаться по сути с другими строками того же направления
- **Аудитория** — конкретный сегмент (профессии, типы бизнеса), не «все»
- **Модель цены** — варьировать формат подачи (за единицу / за проект / за изделие / расчёт по ТЗ),
  это само по себе помогает отличать объявления друг от друга
