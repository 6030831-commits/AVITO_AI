# Тулкит для написания объявлений на Авито (любая тематика)

Набор шаблонов и скриптов, обкатанных на проекте «ЧПУ-фрезеровка / столярка / декорации».
Все файлы очищены от тематических данных — только методология и параметризуемый код.

## Из чего состоит

| Файл | Назначение |
|---|---|
| [01-research-template.md](01-research-template.md) | Шаблон конкурентного анализа: сбор цен, медиана рынка, стратегия −10% |
| [02-seo-checklist.md](02-seo-checklist.md) | Чек-лист SEO-приёмов для заголовка и описания (структура ИНФОРМА) + чек-лист перед публикацией |
| [03-matrix-template.md](03-matrix-template.md) | Шаблон матрицы уникальных связок «направление → изделие → ключ → аудитория → цена» |
| [04-listing-template.md](04-listing-template.md) | Шаблон одного объявления: заголовок, 7-блочное описание, характеристики карточки |
| [05-similarity-checker.py](05-similarity-checker.py) | Скрипт проверки попарной уникальности текстов (Jaccard по словам + биграммам) |
| [06-tracker-generator.py](06-tracker-generator.py) | Генератор xlsx-трекера публикации (статусы, дропдауны, форматирование) |
| [07-batch-publication-guide.md](07-batch-publication-guide.md) | Шаблон плана пачечной публикации без риска склейки в дубли |

## Сквозной процесс (от ниши к опубликованным объявлениям)

```
1. Исследование конкурентов          → 01-research-template.md
   (Firecrawl scrape/map, НЕ свой аккаунт Авито, НЕ парсеры на регулярках)
        ↓
2. Матрица уникальных связок          → 03-matrix-template.md
   (N строк, без повторов ключей внутри направления)
        ↓
3. Тексты объявлений по матрице        → 04-listing-template.md + 02-seo-checklist.md
   (применять чек-лист как стратегию, не копировать формулировки конкурентов)
        ↓
4. Проверка уникальности               → 05-similarity-checker.py
   (порог 40% пересечения — переписать пары выше порога)
        ↓
5. Трекер для ручной заливки           → 06-tracker-generator.py
        ↓
6. План пачечной публикации            → 07-batch-publication-guide.md
   (5 / 10 / 15 вперемешку по направлениям, пауза 1–2 дня)
```

## Как адаптировать под новую тематику

1. Замените в `01-research-template.md` направления услуг и единицы цены на свои
2. Замените в `03-matrix-template.md` список направлений, материалов/вариантов исполнения, аудиторий
3. В `04-listing-template.md` замените производственные параметры (станки, форматы файлов, материалы) на параметры вашего бизнеса
4. Скрипты `05` и `06` — без изменений, читают любые `.md`/`.xlsx` по параметрам в начале файла

## Ключевые правила (не зависят от тематики)

- Заголовок ≤ 50–55 символов, ключевое слово первым словом
- Описание — 7 блоков в строгом порядке (см. 02-seo-checklist.md)
- Цена — конкретное число с единицей измерения, не «договорная»
- Срок — конкретный («от 2 дней»), не «быстро»
- Каждое объявление — уникальная связка: направление + изделие + материал + ключ + аудитория + модель цены
- Пересечение текстов между объявлениями — не более 30–40% (проверять скриптом)
- Без контактов в тексте, без фейковых артикулов/ГОСТ
- Заполнять характеристики карточки — это влияет на ранжирование
