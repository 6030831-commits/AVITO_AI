# Чек-лист SEO-приёмов для объявлений на Авито (универсальный)

> Структура отработана на эталонном аккаунте с максимальным органическим охватом
> (масштабная гео-стратегия: десятки объявлений в 40+ городах при органическом росте за 3 года).
> Применять как СТРАТЕГИЮ — приёмы переносимы в любую тематику, формулировки конкретного аккаунта копировать нельзя.

---

## 1. Структура заголовка

- **Приём 1.** Формула: `[Продукт1 / Продукт2 / Продукт3] для [применение]`
  Слеш объединяет несколько запросов клиента в одном заголовке → один листинг отвечает на несколько поисковых фраз
- **Приём 2.** Ключевое слово — первое слово заголовка (Авито ранжирует по началу строки)
- **Приём 3.** Длина заголовка — 40–55 символов (умещается в карточку без обрезания)
- **Приём 4.** Аудитория/применение — после слова «для», конкретно (не «для всех», а «для ресторана», «для спортивных команд», «для маркетплейса»)

## 2. Структура описания — семь блоков строго по порядку

1. **Бренд + позиционирование** — первая строка: `[НАЗВАНИЕ/тип] [тип производства] — [суть в 3 словах]`
2. **Цикл через стрелки** — этапы работы через `→`: «приём заявки → производство → доставка»
   (сразу ясно: услуга «под ключ», а не частичная)
3. **Цена в первом экране** — конкретное число с единицей измерения: «от X ₽/ед.»
   Правило: никогда не «договорная» / «уточняйте». Диапазон — указывать нижнюю границу
4. **Доп. сервисы с ценами** — каждый сервис отдельной строкой со своей ценой
5. **Технические параметры** — конкретные цифры (размеры, точность, материалы, мощности)
6. **Срок** — конкретный: «от 2 дней», никогда не «быстро» / «в кратчайшие сроки»
7. **Бесплатный бонус** — снижение барьера входа: «расчёт стоимости — бесплатно», «консультация — бесплатно»

## 3. Ключевые слова и плотность

- Основной ключ — в заголовке, один раз
- Производные ключи (синонимы продукта, применения, материалы) — органично в описании
- Не повторять одно слово чаще 2 раз в описании — переспам не повышает ранг
- Каждое объявление получает уникальный ключ в заголовке — листинги одного аккаунта не должны конкурировать друг с другом

## 4. Минимальный заказ — в тексте, не только в карточке

Клиент должен увидеть условие («минимум 5 шт.», «от 2 500 ₽») до звонка/сообщения — это фильтрует нецелевые обращения.

## 5. Гео-стратегия (масштабирование охвата)

| Принцип | Реализация |
|---|---|
| 1 продукт × N городов = N объявлений | Отдельный листинг под каждый целевой город/район |
| Идентичная структура, уникальный город | Менять только гео-привязку — Авито считает их разными листингами |
| Порядок расширения | Свой город → ближайшие города региона → соседние регионы |
| Параллельные направления — разные листинги | Не объединять разные продукты/услуги в одно объявление |

## 6. Уникализация внутри аккаунта

- Разные ключи в заголовках (продукт или применение)
- Разные первые абзацы описаний
- Единая базовая структура — меняется только подстановка под нишу/материал/аудиторию
- Пороговое пересечение текстов — не выше 30–40% (см. [05-similarity-checker.py](05-similarity-checker.py))

## 7. CTA (призыв к действию)

Работает — конкретное действие + обязательство по времени:
- «Пришлите размеры — посчитаем стоимость за 30 минут»
- «Напишите в сообщения — отвечаем в течение часа»

Не работает — без конкретики:
- «Звоните!», «Пишите!», «Обращайтесь!»
