# Шаблон: конкурентный анализ рынка на Авито

> Цель — собрать реальные цены конкурентов и вывести целевую цену по принципу «−10% от медианы рынка».
> Сбор данных — только через Firecrawl (scrape / map / extract). НЕ парсеры на регулярках, НЕ свой аккаунт Авито.
> Поля, которых нет на странице — оставлять `null`, ничего не достраивать.

---

## Шаг 1. Сбор данных

1. Определите 3–6 направлений услуг внутри вашей тематики (аналог «ЧПУ / столярка / декорации»)
2. Для каждого направления найдите 5–15 конкурентов на Авито (через Firecrawl map/search по ключевым запросам)
3. Соберите по каждому листингу: продавец, заголовок, цена (как объявлена), модель подачи цены (за заказ / за деталь / за пог.м / за проект)
4. Сохраните сырые данные в `competitors-data*.json` (структурированно, через Firecrawl extract)

## Шаг 2. Таблица конкурентов (на каждое направление)

| Продавец | Заголовок листинга | Цена (объявленная) | Модель подачи цены |
|---|---|---|---|
| [имя] | [текст из карточки] | [цена] | [за заказ / за деталь / за ед. изм. / за проект] |

## Шаг 3. Частотный анализ ключевых слов

**В заголовках (по убыванию частоты):**
`[слово1]` (X%), `[слово2]` (X%), ...

**В описаниях (часто встречающиеся обороты):**
`[оборот1]`, `[оборот2]`, ...

> Эти слова и обороты — материал для матрицы ключей (шаг 3 общего процесса), но НЕ для копирования формулировок.

## Шаг 4. Расчёт медианы цены и целевой цены

Для каждого направления и единицы измерения:

1. Соберите массив цен: `[v1, v2, ..., vn]`
2. Отсортируйте по возрастанию
3. Медиана:
   - нечётное n → среднее значение
   - чётное n → среднее двух центральных значений
4. Целевая цена = медиана × 0.9 (округлить до удобного числа)

**Шаблон таблицы:**

| Направление | Единица | Медиана рынка | Цель −10% | n записей |
|---|---|---|---|---|
| [направление 1] | [₽/ед / за заказ / за проект] | [медиана] | **[медиана × 0.9]** | [n] |
| [направление 2] | ... | ... | **...** | ... |
| [направление 3] | ... | ... | **...** | ... |

> Если n < 8 — пометить `⚠ данных мало, сверить перед запуском`.

## Шаг 5. SEO-образец (поиск эталона для стратегии)

Среди конкурентов найдите 1 аккаунт с наибольшим органическим охватом
(признаки: много объявлений, гео-стратегия по городам/районам, давний аккаунт с органическим ростом).

Изучите его:
- Структуру заголовков (формулу построения)
- Структуру описаний (порядок блоков)
- Гео-стратегию (если есть — сколько городов, как меняется текст)
- CTA-формулировки

Зафиксируйте находки как **чек-лист приёмов** (см. [02-seo-checklist.md](02-seo-checklist.md)) —
приёмы переносимы в любую тематику, формулировки конкурента — нет.

## Итоговая структура файла research.md

```
# Конкурентное исследование: [ваша тематика] на Авито ([город])

## Раздел 1. Конкуренты и цены
   1.1 Направление 1 — таблица конкурентов, частотный анализ, расчёт медианы
   1.2 Направление 2 — ...
   1.3 Направление 3 — ...
   Сводная таблица по направлениям (медиана / цель −10%)

## Раздел 2. SEO-образец [имя эталонного аккаунта]
   2.1 Чек-лист приёмов (заголовок, описание, ключи, гео-стратегия, CTA)
   2.2 Чек-лист проверки перед публикацией (12 пунктов)
```
