# 29. ИИ-видео из фото для соцсетей

**Группа:** Контент
**Заголовок (29 симв.):** `ИИ-видео из фото для соцсетей`
**Ключи:** ии видео из фото, генерация видео, видео для соцсетей нейросеть
**Цена (вилка по ресёрчу, см. docs/research-uslugi-ai.md):** от 700 до 2 500 ₽ за фото товара, пакеты от 10 шт. со скидкой — выставить
итоговую цифру после сверки владельцем, в карточке — «договорная» либо «от …».

## ОПИСАНИЕ

Статичных фото для соцсетей и карточек уже мало, а снимать видео — отдельная история с
бюджетом и площадкой? Сделаю динамичный контент из ваших изображений.

Из готового фото товара или сцены генерирую короткое видео — для ленты, карточек,
рекламы. Всё на облачных API, без GPU-серверов у вас: решение масштабируется и не
требует своего железа.

Польза: оживляете каталог и соцсети без съёмочной группы, больше форматов из одного
исходника, контент под разные площадки.

Видео-генерацию я встраивал в полноценный контент-пайплайн и передавал с документацией,
чтобы клиент управлял им сам. Производственная привычка (свой цех с 2016 года) —
доводить до рабочего инструмента, а не до демо. Опишите в чат, какой контент нужен.

## ХАРАКТЕРИСТИКИ

- Категория/подкатегория: уточнить при публикации (карта услуг → подкатегории Авито)
- Формат работы: удалённо по РФ
- Опыт: производство в Москве с 2016 года
- Срок выполнения: проставить конкретику после оценки задачи (не «быстро»)
- Портфолио/кейсы: см. макет карточки (промпт 6 / web-designer)

*(заполнить полностью при публикации — характеристики карточки влияют на ранжирование)*

## МАКЕТ

**Кадры на обложке и в галерее (порядок показа):**
1. Обложка с текстом-наложением: «Из набора фото — готовый видеоролик для соцсетей. Без камеры, монтажа и актёров»
2. Раскадровка готового видео: ключевые кадры ролика, собранного из фото — _ключевая демонстрация — «вот что получится на выходе», за один экран_
3. «Было / стало»: исходные статичные фото → кадры готового видео с движением/анимацией — _показывает трансформацию — статика становится динамикой_
4. Схема конвейера: подборка фото → сценарий/раскадровка → генерация видео ИИ → готовый ролик под формат соцсети — _поясняет процесс для тех, кто никогда не сталкивался с подобным_
5. Готовый пример публикации с видео в ленте/сторис соцсети — _показывает результат «в естественной среде» — там, где его увидит аудитория клиента_

**Разбивка описания на визуальные блоки:**
- Открывающий абзац («Внедряю ИИ в реальные процессы...» / аналог) — крупным
  акцентом/цитатой первым экраном, это и есть крючок-дифференциатор.
- Список «Что закрываю / что делаю» — буллетами с короткими тире, каждый пункт
  с новой строки (не сплошным текстом), чтобы считывался за 2 секунды скролла.
- Абзац про производство в Москве с 2016 года — выделить как отдельный блок
  (жирным или цитатой): это ключевое УТП, не должен теряться в середине текста.
- Финальный CTA («Первый разбор задачи — бесплатно...») — отдельным блоком в
  конце с лёгким визуальным отступом, чтобы не сливался с описанием услуги.

**Характеристики карточки для заполнения:**
- Формат работы: удалённо по РФ
- Опыт: производство в Москве с 2016 года
- Срок выполнения: указать конкретный диапазон после оценки задачи (не «быстро»)
- Формат результата: видеоролики под форматы соцсетей (вертикальные/квадратные, с учётом требований площадок)
- Что нужно от клиента: набор исходных фото (товара, бренда, процесса) — без необходимости видеосъёмки
- Длительность и стиль: согласовываются под задачу (анонс, обзор товара, атмосферный ролик и т.п.)

**Визуалы, которые нужно получить от владельца:**
- Набор исходных фото клиента (товар/бренд/процесс), из которых можно собрать ролик
- Демонстрационный пример готового видео из фото в похожем стиле (согласованный тестовый образец)
- Площадки и форматы, под которые нужен ролик (Instagram*/Telegram/VK и т.п. — для требований по формату)
- На всех скринах из реальных кейсов — затереть суммы, названия клиентов/поставщиков, контакты, внутренние номера заказов перед публикацией.
