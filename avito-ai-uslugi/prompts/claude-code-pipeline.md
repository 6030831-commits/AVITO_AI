# Промпты для Claude Code — автоматизация Авито (услуги ИИ-автоматизации)

Тот же принцип, что в основном проекте: **чат пишет промпты → Claude Code собирает
код, агентов, тексты, ноды n8n и трекер**. Скармливай по одному, по порядку.

## Подготовка (один раз)
1. Положи этот репозиторий в работу, запусти Claude Code в его корне.
2. В `docs/` уже лежат: `1-uslugi-matrica-30.md`, `2-obyavleniya-30.md`,
   `3-pravila-unikalizacii.md`.
3. Выпусти **Client ID + Client Secret** на `avito.ru/professionals/api`. Для API
   мессенджера (автоответы) нужен активный платный тариф.
4. Реши, на каком аккаунте публикуешь услуги ИИ — **отдельно от столярного frezorez**
   (разные направления, не смешивать).

## Что Claude Code сделает, а что нет
- ✅ Обёртка Avito API, обновление агентов, проверка уникализации, ноды n8n, трекер.
- ⛔ Не запустит API без реальных ключей + тарифа (код готов, заработает после ключей).
- ⚠️ «Живые цены» из ресёрча — приблизительны; медиану сверить глазами.

## ПРОМПТ 1 — Каркас и гигиена секретов
```
Создай структуру проекта автоматизации Авито для услуг ИИ-автоматизации: src/, n8n/,
docs/ (уже есть), prompts/listings/, tests/. Сделай .env.example с переменными
AVITO_CLIENT_ID, AVITO_CLIENT_SECRET, ANTHROPIC_API_KEY, TELEGRAM_BOT_TOKEN,
TELEGRAM_OWNER_CHAT_ID, AVITO_WEBHOOK_SECRET. Добавь .gitignore, исключающий .env,
*.key, secrets/. Настрой Python-проект (requirements.txt: httpx, python-dotenv,
anthropic, openpyxl). Добавь pre-commit hook, не дающий закоммитить строки, похожие на
ключи. Секреты только из .env, никогда в коде.
```

## ПРОМПТ 2 — Обёртка официального Avito API
```
Напиши тонкую Python-обёртку над ОФИЦИАЛЬНЫМ Avito API (база https://api.avito.ru).
Эндпоинты и поля — из актуальной доки developers.avito.ru, не выдумывай. Реализуй:
OAuth client_credentials с кэшем токена по expires_in; items (список объявлений,
статистика просмотров/контактов, apply_vas); autoload (загрузка XML-фида, отчёт);
messenger (чаты, сообщения, отправка); проверку подписи вебхука по заголовку
x-avito-messenger-signature. Scope: items:info, items:apply_vas, autoload:reports,
messenger:read, messenger:write. Обработка ошибок и ретраи. Тесты с моками, без
реальных сетевых вызовов. ПАРСЕРЫ НЕ ПИШИ — только официальный API.
```

## ПРОМПТ 3 — Агенты под направление «услуги ИИ-автоматизации»
```
Создай/обнови в ~/.claude/agents/ агентов под это направление:
- market-researcher: ниша «автоматизация бизнеса, чат-боты, n8n, ИИ-интеграция» в гео
  Москва/удалённо по РФ; конкуренты на Авито в категориях IT/деловые услуги, их модели
  ценообразования (за проект / за час / абонентка), частотные ключи заголовков.
- avito-copywriter: пишет под ключи, ОБЯЗАТЕЛЬНО вшивает производственный опыт (свой
  цех с 2016, ЧПУ/металл/дерево/пластик) разными формулировками; правила уникализации
  из docs/3 (пересечение <30–40%, разные зачины/шаблоны/синонимы/CTA, без контактов в
  тексте, без фейковых ГОСТ).
- web-designer: макет карточки услуги (порядок скринов/кадров кейсов, блоки описания,
  список характеристик карточки).
- client-comms: черновики ответов покупателям услуг + правила эскалации (как только
  клиент описывает конкретную задачу/ТЗ → передать владельцу для оценки).
Обнови /project: принимает направление и прогоняет researcher → copywriter →
web-designer → client-comms.
```

## ПРОМПТ 4 — Ресёрч конкурентов и цены
```
Запусти market-researcher по нише «автоматизация бизнеса / чат-боты / n8n / интеграция
ИИ», гео Москва + удалённо по РФ. Нужно: топ исполнителей на Авито в категориях
IT/деловые услуги, их модель цен (за проект / почасовая / абонентская поддержка /
«договорная»), вилки цен по типовым услугам (бот, пайплайн n8n, сайт, распознавание
документов), частотные ключи из заголовков. Источники — web-ресёрч и поисковые
подсказки Авито; парсинг в продакшен НЕ использовать. На выходе — таблица конкурентов
и рекомендованные вилки цен по каждой из 6 групп услуг. Пометь, что цены приблизительны
и владельцу стоит сверить вручную. Сохрани в docs/research-uslugi-ai.md.
```

## ПРОМПТ 5 — Уникализация и проверка пересечений
```
Прочитай docs/2-obyavleniya-30.md и docs/3-pravila-unikalizacii.md. Разложи 30
объявлений по отдельным файлам в prompts/listings/ (по одному на объявление: заголовок,
ключи, описание). Проверь попарное пересечение текстов: построй матрицу сходства (можно
по shingles/Jaccard на нормализованном тексте). Любую пару с пересечением выше ~40%
автоматически перепиши через avito-copywriter (смени зачин, шаблон, синонимы, CTA,
переставь упоминание опыта), сохраняя смысл и производственный акцент. Подставь цены из
docs/research-uslugi-ai.md (вилки «от» / «договорная»). В конце выведи итоговую матрицу
пересечений, чтобы я видел, что почти-дублей нет.
```

## ПРОМПТ 6 — Макеты карточек
```
Для текстов из prompts/listings/ прогони web-designer: по каждому объявлению дай макет
карточки — какие кадры на главном и в галерее (скрины кейсов: свой сайт frezorez.ru,
фрагмент расчётной Excel-таблицы, схема пайплайна n8n, кадры контент-конвейера),
разбивку описания на блоки, список характеристик карточки для заполнения (влияет на
ранжирование). Под каждое направление укажи список нужных визуалов, которые
предоставит владелец.
```

## ПРОМПТ 7 — n8n: автоответы клиентам услуг (Вариант Б, self-hosted)
```
Собери n8n-workflow автоответов на сообщения Авито через Claude API, экспорт в
n8n/avito-autoreply-uslugi.json. Логика:
1) Webhook-триггер: входящее сообщение Авито, проверка подписи x-avito-messenger-signature
   (секрет из env n8n).
2) Контекст: тянет объявление и историю чата через messenger:read (нашей обёрткой или
   HTTP-нодой к api.avito.ru).
3) Нода Claude (Messages API, claude-sonnet-4-6) с системным промптом из client-comms:
   тон практика, упор на производственный опыт, мягкая квалификация (какая задача, какой
   объём, какие сервисы). Выход: текст ответа + флаг escalate=true, если клиент описал
   конкретную задачу/ТЗ или дело идёт к заказу.
4) Ветвление: escalate=false → ответ через messenger:write; escalate=true → клиенту
   мягкое «передал, вернусь с оценкой» + уведомление владельца в Telegram (токен/чат из
   env) с текстом клиента и ссылкой на чат.
5) Follow-up: прочитал и молчит N часов → одно вежливое напоминание.
Классификацию escalate для удешевления можно вынести на claude-haiku-4-5-20251001.
Секреты — только из env n8n. В конце опиши, какие credentials и какую webhook-подписку
в кабинете Авито настроить (напомни про платный тариф и scope messenger:read/write).
```

## ПРОМПТ 8 — Трекер заливки


## Порядок и зависимости
- 1 → 2 → 3 подряд (каркас, обёртка, агенты).
- 4 (цены) до 5 (тексты используют цены).
- 5 → 6 (макеты по готовым текстам).
- 7 (n8n) независим, заработает с ключами + тарифом + scope мессенджера.
- 8 (трекер) в любой момент.

## Остаётся на владельце
- Реальные визуалы кейсов (скрины сайта, таблиц, схем, контента).
- Оплата тарифа Авито и выпуск ключей.
- Сверка цен и финальное «да» на публикацию.
- Финальная оценка конкретных заказов (бот квалифицирует и эскалирует).
