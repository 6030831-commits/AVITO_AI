# Правила уникализации и работы по-белому (услуги ИИ-автоматизации)

## Зачем
30 объявлений на родственные услуги с одного аккаунта — высокий риск, что Авито сочтёт
часть из них почти-дублями. Авито банит **дубли**, но не банит **реально разные
предложения**. Уникальность должна быть структурной и смысловой, а не косметической.

## Жёсткие правила текста
1. **Заголовок ≤ 50 символов.** Проверять фактическую длину, а не «на глаз».
2. **Без контактов в теле объявления.** Ни телефона, ни ника, ни ссылок. Контакт —
   через чат Авито и поля карточки. Контакты в описании услуг → риск модерации.
3. **Без водяных знаков с контактами на фото** — нарушает политику Авито.
4. **Без фейковых ГОСТ, артикулов и непроверяемых цифр.** Только то, что подтверждается
   реальными кейсами (свой сайт, расчётный движок, контент-конвейер).
5. **Цены — после ресёрча**, не из головы. До этого «договорная / расчёт по задаче».

## Уникализация между текстами
- Попарное пересечение текста — **не более ~30–40%**.
- Разные **зачины**: вопрос-боль / утверждение / мини-кейс / «было-стало».
- Разные **шаблоны структуры** (см. матрицу, T1–T6) — чередовать, не лить подряд два
  одинаковых.
- Разные **синонимы**: настрою / соберу / выстрою / подключу / сделаю; рутина / ручная
  работа / однообразные операции; заявки / обращения / лиды; конвейер / пайплайн / связка.
- Разные **CTA**: «опишите задачу» / «пришлите пример» / «расскажите, как сейчас» /
  «напишите нишу».
- **Упоминание опыта** — в каждом тексте, но каждый раз другой формулировкой и в разном
  месте (зачин / середина / финал). Не копировать одну фразу в 30 объявлений.

## Публикация
- Пачками **5 → 10 → 15** с паузами в несколько дней.
- Раскидать по близким, но разным подкатегориям услуг.
- Заполнять **все характеристики** карточки — заполненность параметров влияет на
  ранжирование.

## Проверка перед заливкой (чек)
- [ ] Длина каждого заголовка ≤ 50.
- [ ] В теле нет контактов и ссылок.
- [ ] Матрица попарного пересечения ≤ 40% (промпт 5 проекта).
- [ ] Цены проставлены после ресёрча (промпт 4).
- [ ] Параметры карточки заполнены.
- [ ] Кейсы — только проверяемые, без выдуманных регалий.
