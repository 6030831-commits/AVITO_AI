# Инструкция: от каркаса к живым объявлениям и автоответам

Весь конвейер из `prompts/claude-code-pipeline.md` пройден — ниже не план,
а порядок действий **для владельца**, чтобы превратить готовые материалы
в реальные карточки на Авито и работающего автоответчика.

## 0. Что уже готово (можно не пересобирать)

| Что | Где |
|---|---|

## 1. Подготовка окружения (один раз)

```powershell
cd avito-ai-uslugi
py -3 -m pip install -r requirements.txt
copy .env.example .env
```

Заполнить в `.env`:
- `AVITO_CLIENT_ID` / `AVITO_CLIENT_SECRET` — выпустить в кабинете
  разработчика (platform.avito.ru) **после подключения платного тарифа**
  (без него недоступны Messenger API и подписка на вебхуки — это
  принципиально для шага 5).
- `AVITO_USER_ID` — числовой id вашего аккаунта (профиль в кабинете).
- `AVITO_WEBHOOK_SECRET` — задаётся при подписке вебхука (см. шаг 5).
- `ANTHROPIC_API_KEY` — console.anthropic.com → API Keys.
- `TELEGRAM_BOT_TOKEN` / `TELEGRAM_OWNER_CHAT_ID` — бот через @BotFather,
  chat_id — через @userinfobot или аналог.

Проверить, что обёртка над API работает (тесты идут на моках, без
реальных обращений к Avito):
```powershell
py -3 -m unittest discover tests -v
```

## 2. Сверить вручную перед публикацией (нельзя пропускать)

Это явные «домашние задания владельцу», отмеченные в материалах:

- **Цены.** В `docs/research-uslugi-ai.md` — вилки по 6 группам с
  обоснованием, но они получены веб-поиском, а не из живой выдачи Авито.
  Открыть Авито, посмотреть актуальные предложения в категориях «Деловые
  услуги» и «IT, интернет, телеком», поправить вилки под свою загрузку и
  реальную себестоимость часа. Итоговую цифру (или «от …») проставить в
  карточке — в текстах объявлений намеренно оставлено «договорная»/«от …».
- **Визуалы.** В каждом файле `prompts/listings/NN-*.md`, раздел
  `## МАКЕТ` → «Визуалы, которые нужно получить от владельца» — точный
  список (скрины реальных кейсов, чертежи, фрагменты таблиц). Везде
  отдельным пунктом — что именно затереть перед публикацией (суммы,
  имена клиентов, номера заказов).
- **Длина заголовков и характеристики карточки** — в шапке каждого файла
  объявления указано число символов; в `## МАКЕТ` — конкретный список
  характеристик для заполнения формы (влияют на ранжирование).

## 3. Публикация — по пачкам, не разом

Порядок и состав пачек — в `docs/1-uslugi-matrica-30.md`:
- **Пачка 1 (5 шт.):** №№ 1, 4, 11, 16, 21 — флагманы из каждой группы.
- **Пачка 2 (10 шт.):** №№ 2, 3, 6, 7, 12, 17, 18, 22, 26, 27.
- **Пачка 3 (15 шт.):** остальные 15.

На каждое объявление:
1. Открыть `prompts/listings/NN-*.md` → скопировать заголовок и текст из
   `## ОПИСАНИЕ` в карточку.
2. Заполнить характеристики и собрать обложку/галерею по порядку кадров
   из `## МАКЕТ` (с уже подготовленными и анонимизированными визуалами).
3. Проставить цену (см. шаг 2).
4. В `docs/avito-tracker.xlsx`: сменить статус черновик → на модерации →
   опубликовано, вписать дату, ссылку на карточку; позже — просмотры и
   количество обращений (для оценки конверсии заголовка/цены).

Между пачками — пауза (несколько дней), чтобы оценить отклик и при
необходимости поправить цены/заголовки следующей пачки до заливки.

> Если позже понадобится перегенерировать трекер (например, после правок
> в `docs/avito-tracker.csv`): `py -3 tools/generate-tracker.py`.
> Если будете добавлять/менять тексты объявлений — повторно прогнать
> `py -3 tools/check-similarity.py` и переписать пары, которые превысят
> порог 40% (правила — в `docs/3-pravila-unikalizacii.md`).

## 4. Запуск автоответчика (n8n + Claude API)

Полная инструкция с таблицей credentials и порядком действий в кабинете
Авито — в [`n8n/README.md`](../n8n/README.md). Коротко:

1. Поднять self-hosted n8n (Вариант Б — без аренды чужого SaaS).
2. Импортировать `n8n/avito-autoreply-uslugi.json`.
3. Прописать переменные окружения n8n (см. таблицу в `n8n/README.md`):
   ключи Avito и Anthropic, `AVITO_USER_ID`, Telegram-бот, секрет
   вебхука, порог молчания для follow-up.
4. Активировать воркфлоу, скопировать Production URL вебхука.
5. В кабинете Авито подписаться на вебхук (`POST /messenger/v3/webhook`
   с этим URL и секретом — пошагово в `n8n/README.md`), убедиться, что
   выпущены scope `messenger:read`, `messenger:write`, `items:info`.
6. Отправить тестовое сообщение в свой чат и проверить в логах n8n всю
   цепочку: подпись → контекст → ответ Claude → сообщение клиенту или
   эскалация в Telegram.

Перед включением в проде — пройтись по чек-листу «Что проверить вручную»
в конце `n8n/README.md` (особенно: реальный алгоритм подписи вебхука по
факту первых сообщений — сейчас используется обоснованное предположение
HMAC-SHA256, и кеширование токена Avito для продакшен-нагрузки).

## 5. Если нужно расширить ассортимент услуг

Не пишите тексты с нуля — прогоните по новому направлению готовый
конвейер агентов:

```
/project <направление услуг, например: "автоматизация склада и инвентаризация">
```

Команда (`~/.claude/commands/project.md`) последовательно вызовет
`market-researcher` → `avito-copywriter` → `web-designer` → `client-comms`
и обновит `docs/research-uslugi-ai.md`, добавит файл(ы) в
`prompts/listings/`, соберёт макет и черновики ответов — в той же логике
и с той же защитой от дублей, что и для исходных 30.
