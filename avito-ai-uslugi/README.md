# Авито: услуги ИИ-автоматизации — проект для Claude Code

Направление: продажа **услуг ИИ-автоматизации и интеграции ИИ** на Авито. Отдельно от
столярного frezorez — это разные направления, не смешивать. Сквозной аргумент во всех
текстах: владелец действующего производства (Москва, с 2016), который сам построил и
обкатал автоматизацию на своём бизнесе.

## Что внутри
```
docs/
  1-uslugi-matrica-30.md       30 услуг: группа, заголовок, ключ, боль, шаблон, пачки
  2-obyavleniya-30.md          исходный черновик 30 заголовков + описаний
  3-pravila-unikalizacii.md    правила по-белому и анти-дубль
  4-instrukciya-zapuska.md     ← НАЧАТЬ ЗДЕСЬ: пошаговый запуск и публикация
  research-uslugi-ai.md        ресёрч цен и конкурентов по 6 группам услуг
  avito-tracker.csv/.xlsx      трекер заливки, 30 строк, статус «черновик»
prompts/
  claude-code-pipeline.md      8 промптов конвейера (пройден полностью)
  listings/01…30-*.md          готовые тексты + макеты карточек (## ОПИСАНИЕ /

                               подпись вебхука) + tests/ на моках (httpx.MockTransport)

tools/                         check-similarity.py, generate-tracker.py
.env.example  .gitignore  requirements.txt  pyproject.toml
```

## Как пользоваться
Конвейер из `prompts/claude-code-pipeline.md` пройден целиком — каркас,
обёртка API, агенты, ресёрч цен, 30 уникализированных текстов с макетами
карточек, n8n-автоответчик и трекер заливки уже собраны и закоммичены.

**→ Дальше — по шагам в [`docs/4-instrukciya-zapuska.md`](docs/4-instrukciya-zapuska.md):**
подготовка `.env`, что нужно сверить вручную (цены, визуалы), порядок
публикации по пачкам, запуск n8n-автоответчика и как добавить новое
направление услуг через команду `/project`.

## Решения по умолчанию (поправь, если иначе)
- Услуги ИИ публикуются на **отдельном аккаунте/в отдельных подкатегориях**, не вместе
  со столяркой.
- **Контактов в тексте нет** — увод в чат Авито (меньше риска модерации и блокировки
  повторов).
- **Цены — «договорная»** до ресёрча; финальные вилки ставишь сам.
- Автоответы — **Вариант Б (n8n + Claude API на своём VPS)**, как в основном проекте.

## На владельце
Реальные визуалы кейсов · оплата тарифа Авито и выпуск ключей · сверка цен · финальная
оценка конкретных заказов.
